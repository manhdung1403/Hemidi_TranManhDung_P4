# Hemidi TranManhDung P4

## Cài đặt

Yêu cầu đã cài đặt Node.js và npm. Tại thư mục gốc của dự án, chạy:

```bash
npm install
npx playwright install chromium
```

## Chạy kiểm thử

Chạy toàn bộ kiểm thử:

```bash
npx playwright test
```

Mở giao diện Playwright để chọn và theo dõi kiểm thử:

```bash
npx playwright test --ui
```
